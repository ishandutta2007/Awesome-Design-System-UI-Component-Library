# Top Design System & UI Component Library
**Curated List of SaaS Products & Open-Source GitHub Projects**

*Focused on Design Systems, UI Component Libraries, Design Tokens & Accessible Interface Patterns*

**Last updated: October 2026**

This repository tracks notable **SaaS / company design systems** and **open-source projects** for **Design Systems and UI Component Libraries**. These resources help teams build consistent, accessible, and scalable user interfaces through shared principles, tokens, components, and documentation.

**Examples** include Adobe Spectrum, Google Material Design System, Salesforce Lightning Design System, Microsoft Fluent Design System, Atlassian Design System, Shopify Polaris, IBM Carbon Design System, GitHub Primer, Ant Design, and Tailwind UI (the category leaders).

**Open-source emphasis**: Design systems and UI libraries have one of the strongest open-source ecosystems in frontend development. **IBM Carbon**, **GitHub Primer**, **Ant Design**, **Fluent UI**, **React Spectrum**, **MUI**, **shadcn/ui**, **Chakra UI**, **Radix UI**, and many others provide production-ready, accessible components under permissive licenses. This section is heavily expanded.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms
- **[Adobe Spectrum](https://spectrum.adobe.com/)**  
  Adobe’s design system providing guidelines, design tokens, and components used across Adobe products, with strong accessibility focus and open-source React implementations.

- **[Google Material Design](https://m3.material.io/)**  
  Google’s comprehensive design system (Material Design 3) offering principles, components, and guidance for Android, web, and multi-platform experiences.

- **[Salesforce Lightning Design System](https://www.lightningdesignsystem.com/)**  
  Design system powering Salesforce products, with detailed component guidelines, accessibility standards, and developer resources.

- **[Microsoft Fluent Design System](https://fluent2.microsoft.design/)**  
  Microsoft’s design language and system used across Windows, Office, and web products, emphasizing depth, motion, and cross-platform consistency.

- **[Atlassian Design System](https://atlassian.design/)**  
  Design system used by Jira, Confluence, and other Atlassian products, with components, foundations, and content guidelines.

- **[Shopify Polaris](https://polaris.shopify.com/)**  
  Shopify’s design system for building consistent merchant experiences, including React components and design guidance.

- **[IBM Carbon Design System](https://carbondesignsystem.com/)**  
  IBM’s open design system with extensive components, patterns, and guidance (also listed in open-source due to its fully open nature).

- **[GitHub Primer](https://primer.style/)**  
  GitHub’s design system used to build github.com, offering React components, CSS, and design tokens.

- **[Ant Design](https://ant.design/)**  
  Enterprise-class UI design language and React component library widely used for admin interfaces and data-dense applications.

- **[Tailwind UI](https://tailwindui.com/)**  
  Official premium component collection built with Tailwind CSS, offering polished, production-ready UI patterns (complements the open-source Tailwind CSS).

## Open-Source GitHub Projects
- **[IBM Carbon](https://github.com/carbon-design-system/carbon)**  
  Fully open-source design system from IBM with React, Web Components, Angular, and Vue implementations. Strong accessibility (WCAG) and enterprise adoption.

- **[GitHub Primer](https://github.com/primer)**  
  Open-source design system powering GitHub. Includes React components, CSS, design tokens, and Figma resources under a permissive license.

- **[Ant Design](https://github.com/ant-design/ant-design)**  
  Popular enterprise React UI library with a comprehensive set of high-quality components, theming, and internationalization support.

- **[Fluent UI](https://github.com/microsoft/fluentui)**  
  Microsoft’s open-source UI framework (React and Web Components) implementing the Fluent Design System with strong accessibility and cross-platform support.

- **[React Spectrum / React Aria](https://github.com/adobe/react-spectrum)**  
  Adobe’s open-source implementation of Spectrum. React Aria provides accessible behavior primitives; React Spectrum delivers styled Spectrum components.

- **[MUI (Material UI)](https://github.com/mui/material-ui)**  
  The most widely used open-source React implementation of Google’s Material Design, with extensive customization, theming, and advanced components.

- **[shadcn/ui](https://github.com/shadcn-ui/ui)**  
  Highly popular collection of re-usable components built with Radix UI and Tailwind CSS. Copy-paste architecture that gives full ownership of the code.

- **[Chakra UI](https://github.com/chakra-ui/chakra-ui)**  
  Modular and accessible React component library with a strong focus on developer experience, theming, and style props.

- **[Radix UI](https://github.com/radix-ui/primitives)**  
  Low-level, unstyled, accessible UI primitives for building high-quality design systems and component libraries.

- **[Shopify Polaris React](https://github.com/Shopify/polaris)**  
  Open-source React components implementing Shopify’s Polaris design system for building consistent admin and merchant interfaces.

### Additional Strong Open-Source Options
- Accessibility-first primitives: **Radix UI**, **React Aria**.
- Full design systems: **Carbon**, **Primer**, **Fluent UI**, **React Spectrum**.
- Material implementations: **MUI**, Material Web Components.
- Utility-first + components: **shadcn/ui**, Headless UI, Tailwind CSS ecosystem.
- Other notable libraries: Ariakit, Headless UI, Park UI, Ark UI, NextUI / HeroUI.
- Accepting that company design systems (Adobe Spectrum, Material Design, Lightning, Fluent, Polaris, Atlassian) provide deep product-specific guidance and design kits, while open-source libraries excel in flexibility, community contributions, and framework integrations.

**Frameworks for building custom systems**:  
Start with accessible primitives (**Radix UI** or **React Aria**) → layer styling with Tailwind CSS or design tokens → adopt or extend a full system (**Carbon**, **Primer**, **shadcn/ui**, or **MUI**) → document with Storybook or similar. Ideal for teams that want full control over code, theming, and long-term ownership.
